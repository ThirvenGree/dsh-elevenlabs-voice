# DSH ElevenLabs Voice

为 DeepSeek Harness Desktop 提供按钮录音、Scribe 批量转写、回答朗读，以及现有 Pet 的实时语音对话。**Core + DSH Voice + Pet Voice** 共用同一个插件和环境变量密钥，保留两端独立配置。

## 使用

1. 在 Windows 中设置 `ELEVENLABS_API_KEY`，完全退出并重新启动 DSH。插件只读取宿主进程的环境变量，不读注册表，不提供密钥输入框。
2. 打开 **DSH 设置 → ElevenLabs Voice**，填写自己的 **Voice ID**，保存。默认 STT 为 `scribe_v2`，TTS 为 `eleven_v4`；可手动填写其他可用模型，例如 `eleven_v4_turbo`。
3. 点击输入框旁的麦克风图标开始录音，按钮变成红色计时，再次点击结束。默认最多 300 秒，到时自动结束并转写。浮动卡片显示计时和音量，可以取消或结束并转写。
4. 转写插入当前光标或替换选区，发送前可编辑。默认**不自动发送**。无有效语音、取消或失败时不提交。
5. 点击回答操作栏里的喇叭图标朗读这条回答，朗读时图标变成停止键；选中该回答的部分正文后点 **朗读选中内容**。浮动卡片支持暂停、继续、重播、关闭、拖动进度和调节音量；长回答分段时，卡片顶部的细线显示总体进度。

设置页提供录音测试和声音试听。试听、转写均会消耗 ElevenLabs 账户额度。术语表会产生额外费用，具体按官方计费规则执行。

### 安装

下载 GitHub Release 的 `.tgz`，通过 DSH 插件安装入口导入，或使用 DSH CLI：

```powershell
dsh plugin --profile desktop add C:\Downloads\dsh-elevenlabs-voice-1.3.0.tgz
```

开发安装：

```powershell
git clone https://github.com/ThirvenGree/dsh-elevenlabs-voice.git
cd dsh-elevenlabs-voice
npm ci
npm run build
dsh plugin --profile desktop add "file:C:/path/to/dsh-elevenlabs-voice"
```

安装后重启 DSH。某些版本的 CLI 会复制本地包而不是建立链接；修改源码后需要重新安装或使用自己的部署脚本同步构建产物。卸载仅移除本插件，不修改 Agent、BrowserSkill、角色、记忆、工作区或历史记录。

## 插入与会话规则

- 转写**完成时**读取原生输入框光标、选区和草稿版本，通过原生 `captureInsertion` / `insertText` 插入，保持一次撤销边界和引用对象。
- 未聚焦的草稿追加到末尾。接缝两侧都是汉字时不补空格，否则补一个空格；已有空白不重复补。
- 录音中切换会话会结束录音并上传，结果始终属于原会话。能够访问原输入壳时写回原草稿；壳已卸载时保留文本，提供复制和手动插入当前会话。
- 原会话已删除时丢弃结果。跨会话返回**绝不自动发送**。
- 录音测试只展示结果，不插入、不自动发送。

## 朗读、缓存与隐私

只取 DSH 会话投影中对应回答的 `text` 块，排除推理、工具调用、工具日志、系统消息；不从整页抓取内容。选区必须位于同一回答所在的聊天轮次内，并能匹配其可见正文。

Markdown 先转换为适合朗读的文字；长回答按句段分块；播放当前段时最多预取下一段，提前停止时下一段可能已产生合成费用。支持的模型传入前后文本与最近三段的请求编号（不超过两小时），使用 request stitching 改善衔接；eleven_v3 不传入此参数。没有摘要模型、额外润色模型、自动朗读、快捷键、SSML、语速或风格滑块。

音频仅保存在当前客户端内存中，按 **会话 + 文本 + Voice ID + 模型 + 输出格式** 缓存，最多 64 段 / 64 MiB。缓存命中直接重播；改变模型或声音重新生成。刷新、关闭或禁用插件会清除缓存。原始录音和音频不写磁盘。测试生成的音频不随代码发布。

非敏感配置保存在 `$DSH_HOME/elevenlabs-voice/config.json`，默认 DSH_HOME 为用户目录下的 `.dsh`。连接诊断只返回环境变量是否存在、请求编号和请求模型，不返回密钥，也不保存转写原文或请求正文。服务端没有返回模型确认头时，诊断不会把请求模型伪装成已确认模型。

本机接口检查 loopback Host、实际端口、对端地址、Origin 和 CSRF token，防止跨站或 DNS 重绑定请求。请求设超时和并发上限；禁用或卸载会取消运行中的服务调用和音频资源。代理仅支持显式填写本机 HTTP 代理，不接受远程代理或嵌入凭据。

## 连接故障

- 缺少环境变量：设置后需要完全重启 DSH，正在运行的进程不会自动继承。
- 无效 key 与缺少权限分别显示；模型列表接口缺少读取权限不等于 key 无效。可手动试听验证 TTS。
- API key 需要有对应 STT / TTS 权限，声音也必须属于账户可用范围。余额、频率限制、网络错误及超时分别提示。
- 麦克风权限须由用户在系统 / 浏览器中授予；输出设备切换依赖浏览器 `setSinkId`，不支持时使用系统默认。

## 扩展结构

`src/core.js` 管理 ElevenLabs API、取消、错误和请求回执；`src/host.js` 提供受保护的本机接口；不注册原生 Speech Provider，避免第二个入口绕过本插件插入规则；`src/client.js` 管理 DSH 插槽、录音、插入及播放；`src/shared.js` 放置配置校验及纯函数；`src/ui-state.js` 管理按需订阅、正文快照索引及共享选区监听。

Pet Voice 已在 1.1.0 接入同一个包。现有 `pet.enabled:false` 字段仅为旧配置兼容；实际每只 Pet 的独立语音设置保存在本机 `elevenlabs-voice/pet.json`，通过 Pet 面板修改。主开关关闭时两端停止；DSH 听写开关不会关闭 Pet 语音。DSH 听写录音期间，Pet 暂停收听和出声，录音结束后自动恢复。

## v1.1.0 Pet 实时语音

在现有 Pet 的右键菜单选择 **语音对话**，也可在 Pet 设置中点 **语音与实时对话设置**。默认跟随 DSH 当前模型；可填写独立 provider/model（必须是 DSH 已配置的路由），不会修改 Agent 的模型。角色继续在现有 Pet / cosplay 中管理，共享模式每轮读取当前人设、生活、心情和已授权记忆。Pet 最近记录与 Agent 会话分开；真实用户话语继续交给已安装生活/记忆插件审核。对话页的「清空对话」只清除这只 Pet 的最近记录（点两次确认），不删除共享长期记忆。

- **开始实时对话**：点击后开启麦克风，Speech Engine 处理识别、轮次、合成和打断，正文交给 DSH LLM 流式生成。停止、关闭面板或禁用后释放录音、连接和动作锁。单次对话默认最长 10 分钟（每只 Pet 可在面板设置中改为 1–60 分钟），到时由 ElevenLabs 结束、面板自动重连继续，中间有短暂停顿；连续三次重连失败才停止。
- **发送并朗读**：不需要麦克风；实时连接中也可用文字打断和继续对话。
- **直接朗读 / 当前台词**：不调用 LLM，使用所选 Voice ID 和 TTS 模型；24 条内存音频缓存，长文分段。默认 `eleven_v4_turbo`，可改 `eleven_v4`。
- **自动出声**默认关闭，只消费已经公开的 Pet 台词，不朗读工具日志；02:00–06:00 安静，默认冷却 30 分钟、每小时最多 3 次。实时对话优先。
- 说话时复用现有 Pet 动作锁暂停动画，结束后恢复。Web 和桌面只允许同一 Pet 的一个音频拥有者，避免重复播放。
- 模型可提议 1 秒至 24 小时的计时器和公开 HTTPS 网页；面板展示确认按钮后才执行。没有文件、终端或任意系统执行权限，复杂任务仍在 DSH 处理。计时器随 DSH 退出取消。

### 为已有 Pet 安装适配

不安装第二个 Pet。先备份现有包，运行：

```sh
node scripts/install-pet-adapter.mjs "你的现有 dsh-pet 包目录" --check
node scripts/install-pet-adapter.mjs "你的现有 dsh-pet 包目录"
```

适配器以现有 0.3.8 代码为基础，只修改匹配的代码片段；无法匹配会在写入前停止。保存修改前备份，随后运行 Pet 的类型、lint、测试、OpenAPI 和构建检查。重启 DSH 后生效。已经适配时可重复检查，不改角色、资源和用户配置。从 1.1.x 升级时重新运行一次即可更新语音浮窗：安装器只替换旧版适配器写入、且未被改动过的 `voice-panel.ts`，本地改过的副本会被拒绝覆盖。其他上游版本需要先核对差异，不能强行覆盖。

### 网络和权限

Speech Engine 必须从 ElevenLabs 连接公开 WSS。此版本用系统 OpenSSH 和 Pinggy 免费临时隧道，仅暴露独立的、带 ElevenLabs 签名校验的上游端口，**不转发 DSH 页面、本机设置或控制接口**。首次建立时自动生成仅供隧道使用的本机 Ed25519 key 和独立 known_hosts，不修改全局 SSH 配置；首次连接自动记录 Pinggy 主机密钥（`accept-new`），之后严格校验。免费隧道限时 60 分钟，45 分钟启动续期并更新引擎地址，旧连接保留最多 10 分钟；空闲后关闭隧道。服务端和网络中断仍可能导致会话重连。无固定域名或付费服务依赖。

**隐私提示**：免费隧道在 Pinggy 一端解密 HTTPS，实时对话的识别文字和 Pet 回复会以明文经过 Pinggy 中继。签名只能使用一次，中继无法借它再建连接，但能看到内容。不希望经过第三方中继时，不要开启实时对话；文字对话和直接朗读不经过隧道。

Key 仍只从 `ELEVENLABS_API_KEY` 读取，需现有 STT/TTS 权限以及 ElevenAgents Write；不发送到浏览器、不写入插件设置。每 Pet 的引擎 ID 保存在本机，重启可复用并更新地址，正常关闭尝试删除；失败记录保留以便下次复用。

本机面板使用随机能力地址、严格 Host/端口/Origin 校验及写请求令牌；公网端口只接受正确路径及未过期的 ElevenLabs HS256 签名，且每个签名只接受一次（按解码后的签名字节判断，换一种 base64url 写法也算同一个）。面板地址有效期 24 小时，不应分享给他人。修改会话或配置时不会复制 DSH API 密钥。

如果一键启动器通过“宿主拥有的第一个端口”寻找 DSH，需要改为验证主服务的 `401 dsh web authentication required` 响应：插件也可以拥有自己的本机监听端口。

官方协议：[Speech Engine](https://elevenlabs.io/docs/eleven-api/guides/cookbooks/speech-engine)、[上游签名和流协议](https://elevenlabs.io/docs/api-reference/speech-engine/speech-engine-upstream)、[JavaScript 客户端](https://elevenlabs.io/docs/eleven-agents/libraries/java-script)、[Pinggy 使用说明](https://pinggy.io/docs/usages/)。


## v1.1.1 后台播放

现有 Pet 自带隐藏的无麦克风播放器，启用自动出声后无需一直打开语音面板。面板打开时优先取得音频所有权，关闭后后台自动恢复；多端仍只播放一次。后台不申请麦克风，默认自动出声关闭，出错时回到 Pet 气泡显示。没有实时连接时关闭公网隧道，后台播放器不会导致隧道持续续期。


## v1.1.2 修复

- 上游签名只接受一次：同一签名在过期前再次握手会被拒绝，防止隧道中继重放。
- DSH 听写与 Pet 互斥：DSH 开始录音时通知宿主，Pet 面板静音麦克风和输出、跳过自动出声；录音结束后恢复。通知按页面和序号排序，开始信号是有时限的租约（录音上限加 60 秒），页面中途关闭也不会让 Pet 一直静音。
- 单次实时对话时长可配置：每只 Pet 的 `sessionMinutes`，默认 10 分钟，范围 1–60。隧道每 45 分钟更换地址、旧地址最多保留 10 分钟，正好跨过这一时刻的对话可能被断开并自动重连。
